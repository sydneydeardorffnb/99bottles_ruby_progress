## Simplicity

- DRY = Don't repeat yourself
- Trading more complexity in one place for less complexity in another
- Resist abstraction until necessary
- Concrete (semantic) vs abstract (dynamic)
- Question of understandability is always present

---

## Judging Code

- Good code = highest value for lowest cost, elegance follows such

### Source lines of code

- Code volume = effort
- Not indicative of quality

### Cyclomatic complexity

- Mathematic technique to determine if code is difficult to test or maintain
- Number of unique execution paths

### ABC

- assignments = count of variable assignments
- branches = function calls or message sends
- conditions = conditional logic
